Run Google's coding agents with the rest.

Antigravity CLI (agy) and Gemini CLI (gemini) both run in a terminal. Skiff is a desktop app for Linux and macOS that runs many terminals at once, next to Claude Code, Codex or any other command line. Each session sits under the project and Git worktree it works in.

What Skiff adds

Skiff's Gemini entry starts agy by default. Set its command to gemini in Settings to run Gemini CLI. Either tool runs unchanged.

Gemini beside other agents

Put up to four sessions in a named group, from any mix of agents. One can write while another reviews.

One worktree per task

Make Git worktrees in Skiff and start a session in each one, so parallel tasks don't edit the same files.

A bell when Gemini asks

Skiff reads the approval prompts of both Antigravity CLI and Gemini CLI from the screen and rings a bell on that session. A flag means it finished while you were elsewhere.

Close the window, keep working

A daemon, skiffd, owns every terminal. The agent keeps going after you close Skiff. Open it again and each terminal shows its last screen.

Changed files and diffs

Each worktree lists the files the agent changed. Double-click one to see the diff, or open it in your own editor.

Agents that start agents

The skiff command lets an agent start more sessions, type into them and wait for them to finish.

Your setup stays yours

Skiff installs no hooks and writes nothing into the agent's configuration. It runs the CLI you signed in to, with your own Google account or API key.

Start in four steps

  1. Install Antigravity CLI from antigravity.google, or Gemini CLI from geminicli.com, and sign in.
  2. Download Skiff for Linux (.deb, .rpm or AppImage) or macOS on Apple Silicon.
  3. Add a project. A project is a Git repository. Make a worktree in it if you want an isolated branch. If you use Gemini CLI, set the Gemini command to gemini in Settings.
  4. Start a Gemini session in the worktree. Add another agent to the same group when you want a second opinion.

Ask your agent

You don't type skiff commands yourself. Ask your agent in plain words, from any Skiff terminal:

Open a Gemini next to me and ask it to review the uncommitted changes. Tell me what it finds.

The agent runs the commands, waits for the other session and reports back. It learns how from the skiff-cli skill. Copy it once into your agent's skills folder, such as ~/.claude/skills/ for Claude Code or ~/.codex/skills/ for Codex. The app does not install it for you.

What the agent runs 
skiff new --agent gemini --name gemini-review
skiff group add . gemini-review --split right
skiff wait gemini-review --for idle --timeout 60
skiff send gemini-review "Review the uncommitted changes" --enter
skiff wait gemini-review --for any-not-working --timeout 600
skiff peek gemini-review

The full list is on the CLI page.

Questions

Antigravity CLI or Gemini CLI?
Skiff supports both under its Gemini entry. It starts agy by default. Change the command in Settings to gemini for Gemini CLI, or add the other one as your own agent to run both.
Does it work with my Google account?
Yes. Skiff starts the same command you run in a terminal, so it uses whatever login that command already has.
Can I run other agents at the same time?
Yes. Skiff also comes with Claude Code, Codex, Grok and OpenCode, and you can add any other command. See Claude Code and Codex in Skiff.
What does it cost?
Nothing. Skiff is open source under the MIT license.
