A small workspace for coding agents.

Run coding agents side by side, in any folder or Git worktree. Tell Admiral, the built-in coordinator, what you need, and it hands the tasks to agents across your projects. They keep running when you close the window.

All screenshots and videos, by version

Admiral hands out the work

Admiral coordinates all your projects. A project or a fleet can also have its own Skipper. Each one is an ordinary agent session that drives other sessions with the skiff command. None of them starts by itself: you click it, or a hand-off from Admiral starts it.

Admiral

The main Skipper has the top row of the sidebar. Ask it for something, and it starts agent panes and sends each one a task, or hands the job to a project's Skipper. Run skiff skipper to reach it from any terminal, over SSH too.

Project Skippers

A project can have one Skipper, which runs in the project's folder. It takes a hand-off from Admiral, starts the task panes it needs and reports back once they are done.

Fleet Skippers

A fleet is a group of projects in the sidebar, and its Skipper covers all of them. If project Skippers already run there, it takes over their work once you confirm.

The Ledger

Every task goes into a ledger. A panel beside each Skipper's pane shows its share of the work in Working, Open and Finished. Rows that need you turn amber.

The watcher

skiff watch tells a Skipper when one of its panes ends a turn, exits or sits idle with a task. A pane that asks for your approval sends you a desktop notification.

Instructions and task types

Every Skipper reads AGENTS.md, and each project or fleet adds its own SKIPPER.md. A task type picks the agent, model and instructions for one kind of task.

The workspace

Agents in panes you can see

Each agent runs in a real terminal pane, side by side. A bell or a flag shows which one needs you.

Close the window, keep the work

A daemon, skiffd, owns every terminal. Agents keep running, and updates keep your sessions.

A worktree per task

New worktree… makes a branch in its own folder next to the project. Start agents in it.

Any folder is a project

Git repositories get worktrees, branches and diffs. Other folders show their files.

Bring your agent

Claude Code, Codex, Gemini, Grok, OpenCode, Hermes and Kimi are built in. Add any other command line.

Images become paths

Drop or paste an image on a pane, and Skiff types its path. Search, pin and insert it again from the library.

Install

Get a .deb, .rpm or AppImage for Linux x86_64, or a .dmg for macOS on Apple Silicon. The skiff command comes with the app. Skiff is free and open source under the MIT license. Go to the downloads.
