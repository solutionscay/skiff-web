Run Codex next to your other agents.

Codex CLI runs in a terminal. Skiff is a desktop app for Linux and macOS that runs many terminals at once: Codex, Claude Code, Gemini CLI or any other command line. Each session sits under the project and Git worktree it works in, and you can see which one needs you.

What Skiff adds

Skiff starts the codex command you already have. Codex itself does not change.

Codex beside Claude Code

Put up to four sessions in a named group, from any mix of agents. One can write while another reviews.

One worktree per task

Make Git worktrees in Skiff and start a Codex session in each one, so parallel tasks don't edit the same files. See the worktree guide.

A bell when Codex asks

Skiff reads Codex's approval prompt from the screen and rings a bell on that session. A flag means it finished while you were elsewhere.

Close the window, keep working

A daemon, skiffd, owns every terminal. Codex keeps going after you close Skiff. Open it again and each terminal shows its last screen.

Changed files and diffs

Each worktree lists the files Codex changed. Double-click one to see the diff, or open it in your own editor.

Agents that start agents

The skiff command lets an agent start more sessions, type into them and wait for them to finish.

Your setup stays yours

Skiff installs no hooks and writes nothing into Codex's configuration. It runs the CLI you signed in to, with your ChatGPT plan or API key. Change the command in Settings if you start Codex with your own flags.

Start in four steps

  1. Install Codex CLI and sign in. OpenAI's Codex CLI docs cover this.
  2. Download Skiff for Linux (.deb, .rpm or AppImage) or macOS on Apple Silicon.
  3. Add a project. A project is a Git repository. Make a worktree in it if you want an isolated branch.
  4. Start a codex session in the worktree. Add Claude Code or another agent to the same group when you want a second opinion.

Pair it from the shell

From any Skiff terminal, these commands start a Codex session beside the current one and hand it a task. See the CLI page for the full list.

skiff new --agent codex --name codex-review
skiff group add . codex-review --split right
skiff wait codex-review --for idle --timeout 60
skiff send codex-review "Review the uncommitted changes" --enter
skiff wait codex-review --for any-not-working --timeout 600
skiff peek codex-review

Questions

How is this different from the Codex app?
The Codex app is OpenAI's own desktop app. Skiff runs the Codex CLI in a terminal and puts other agents' CLIs in the same window, grouped by project and worktree.
Does it work with my ChatGPT plan?
Yes. Skiff starts the same codex command you run in a terminal, so it uses whatever login that command already has.
Can I run Claude Code at the same time?
Yes. Skiff also comes with Claude Code, Gemini, Grok and OpenCode, and you can add any other command. See Claude Code in Skiff.
What does it cost?
Nothing. Skiff is open source under the MIT license.
