Skiff user guide

How to set up Skiff and run coding agents in it, one task at a time. Each step is a click or a key in the app. The guide covers Skiff 1.7.10 on Linux and macOS.

Updated 2026-10-29 · All guides

Before you start

Install Skiff from the download page and open it. The keys in this guide are the Linux keys. On macOS, ⌘+Shift replaces Ctrl+Shift. Press F1 in the app to see every key, with any changes you made.

The screenshots show three sample projects: devbox, atlas and harbor. Your own projects go in their place.

Chapters

  1. Set up Admiral, Skippers and task typesName the Skiff agent, pick its agent and model, and tell it which agent runs each kind of task.
  2. Projects, fleets and the first startAdd projects, put them in fleets, and start Admiral and the Skippers.
  3. Sessions, groups, tiles and themesStart agents, put them side by side, lay out the panes, and give projects and sessions their own look.
  4. Side panel, diffs and filesRead the tree, review a change in the peek, and browse the files of a worktree.
  5. Focus mode, maximize and Mission controlHide the chrome, fill the window with one pane, and see the whole agent hierarchy as a graph.
  6. Drop imagesGive an agent an image, and find it again in the library.
  7. The Ledger and result filesFollow the tasks Admiral and the Skippers run, and open what they wrote.
  8. WorkspacesShow only some projects and fleets, and keep that view in a file.
  9. SettingsAgents, Open with, themes, skiffd activity, disk use and the image gallery.

Where to look next

The wiki has the reference pages: the Glossary, the Skiff agent, Open with and Mission control. The guides cover worktrees, parallel agents and sessions that keep running.
