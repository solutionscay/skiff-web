Download Skiff

The latest release for Linux x86_64 and macOS on Apple Silicon.

Linux .deb

Debian, Ubuntu and their derivatives

Download .deb 
sudo apt install ./Skiff_*_amd64.deb

Linux .rpm

Fedora, openSUSE and other RPM distributions

Download .rpm 
sudo dnf install ./Skiff-*.x86_64.rpm

On openSUSE, use sudo zypper install instead.

Linux AppImage

Any distribution. No install step.

Download AppImage 
chmod +x Skiff_*_amd64.AppImage
./Skiff_*_amd64.AppImage

macOS .dmg

Apple Silicon. Signed and notarized.

Download .dmg

Open the .dmg and drag Skiff to Applications.

Release notes and older versions are on GitHub Releases. To build from source, see the README.
