Run several Claude Code sessions at once.

Claude Code runs in a terminal. Skiff is a desktop app for Linux and macOS that holds many of those terminals. Each session sits under the project and Git worktree it works in, and you can see which one needs you.

What Skiff adds

Skiff starts the claude command you already have. Claude Code itself does not change.

Sessions side by side

Put up to four sessions in a named group and split them left, right, up or down.

One worktree per task

Make Git worktrees in Skiff and start a Claude Code session in each one, so parallel tasks don't edit the same files.

A bell when Claude asks

A bell means a session waits for your approval. A flag means it finished its turn while you were in another pane.

Close the window, keep working

A daemon, skiffd, owns every terminal. Claude keeps going after you close Skiff. Open it again and each terminal shows its last screen.

Changed files and diffs

Each worktree lists the files Claude changed. Double-click one to see the diff, or open it in your own editor.

Claude can run the others

The skiff command lets Claude Code start more sessions, type into them and wait for them to finish.

Your setup stays yours

Skiff installs no hooks and writes nothing into Claude Code's configuration. It runs the CLI you signed in to, with your own plan or API key. You can start Codex, Gemini CLI, Grok, OpenCode or a plain shell next to it.

Start in four steps

  1. Install Claude Code and sign in. Anthropic's Claude Code docs cover this.
  2. Download Skiff for Linux (.deb, .rpm or AppImage) or macOS on Apple Silicon.
  3. Add a project. A project is a Git repository. Make a worktree in it if you want an isolated branch.
  4. Start a claude session in the worktree. Add more sessions to the group as the work grows.

Drive it from Claude

Every Skiff terminal knows its own session, so Claude Code can run commands like these. The skiff command ships with the app. See the CLI page for the full list.

skiff new --agent codex --name review
skiff group add . review --split right
skiff wait review --for idle --timeout 60
skiff send review "Review the diff in this worktree" --enter
skiff wait review --for any-not-working --timeout 600
skiff peek review

Questions

Does Skiff replace Claude Code?
No. Skiff runs the Claude Code CLI in its own terminals. You still install and update Claude Code yourself.
Does it work with my Claude subscription?
Yes. Skiff starts the same claude command you run in a terminal, so it uses whatever login that command already has.
Is there a Windows version?
Not yet. Skiff ships for Linux x86_64 and macOS on Apple Silicon.
What does it cost?
Nothing. Skiff is open source under the MIT license.
