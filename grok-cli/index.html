Run Grok Build with your other agents.

Grok Build, xAI's coding agent, runs in a terminal as grok. Skiff is a desktop app for Linux and macOS that runs many terminals at once: Grok, Claude Code, Codex or any other command line. Each session sits under the project and Git worktree it works in.

What Skiff adds

Skiff starts the grok command you already have. Grok Build itself does not change.

Grok beside other agents

Put up to four sessions in a named group, from any mix of agents. Compare how Grok and another agent handle the same task.

One worktree per task

Make Git worktrees in Skiff and start a session in each one, so parallel tasks don't edit the same files.

A bell when Grok asks

Skiff reads Grok's approval prompts from the screen, including Allow once and Reject for a command, and rings a bell on that session.

Close the window, keep working

A daemon, skiffd, owns every terminal. Grok keeps going after you close Skiff. Open it again and each terminal shows its last screen.

Changed files and diffs

Each worktree lists the files Grok changed. Double-click one to see the diff, or open it in your own editor.

Agents that start agents

The skiff command lets an agent start more sessions, type into them and wait for them to finish.

Your setup stays yours

Skiff installs no hooks and writes nothing into Grok's configuration in ~/.grok. It runs the CLI you signed in to, with your own xAI plan. Change the command in Settings if you start Grok with your own flags.

Start in four steps

  1. Install Grok Build and sign in. xAI's Grok Build docs cover this.
  2. Download Skiff for Linux (.deb, .rpm or AppImage) or macOS on Apple Silicon.
  3. Add a project. A project is a Git repository. Make a worktree in it if you want an isolated branch.
  4. Start a grok session in the worktree. Add another agent to the same group when you want a second opinion.

Ask your agent

You don't type skiff commands yourself. Ask your agent in plain words, from any Skiff terminal:

Open a Grok next to me and ask it to review the uncommitted changes. Tell me what it finds.

The agent runs the commands, waits for the other session and reports back. It learns how from the skiff-cli skill. Copy it once into your agent's skills folder, such as ~/.claude/skills/ for Claude Code or ~/.codex/skills/ for Codex. The app does not install it for you.

What the agent runs 
skiff new --agent grok --name grok-review
skiff group add . grok-review --split right
skiff wait grok-review --for idle --timeout 60
skiff send grok-review "Review the uncommitted changes" --enter
skiff wait grok-review --for any-not-working --timeout 600
skiff peek grok-review

Questions

Which Grok CLI does Skiff run?
Skiff's Grok entry starts the grok command, which is xAI's Grok Build. To run a different tool, change the command in Settings or add it as your own agent.
Does it work with my xAI plan?
Yes. Skiff starts the same grok command you run in a terminal, so it uses whatever login that command already has.
Can I run other agents at the same time?
Yes. Skiff also comes with Claude Code, Codex, Gemini and OpenCode, and you can add any other command. See Claude Code and Codex in Skiff.
What does it cost?
Nothing. Skiff is open source under the MIT license.
